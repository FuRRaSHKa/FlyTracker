# FlyTracker

WPF-приложение для записи вылетов EVE Online по локальным Gamelogs.

## Структура проекта

Исходный код находится в папке `FlyTracker/`:

| Папка | Назначение |
| --- | --- |
| `Views` | Окна WPF: XAML и связанный код взаимодействия с интерфейсом. |
| `ViewModels` | Состояние интерфейса, команды пользователя и обновление привязок. |
| `Commands` | Реализация команд WPF. |
| `Models` | Вылеты, наблюдения из логов и сводки по целям. |
| `Logs` | Чтение, разбор, импорт и обновление игровых логов. |
| `Persistence` | Хранение вылетов и событий в SQLite. |
| `Reports` | Формирование отчёта: урон, маршрут и цели. |
| `Settings` | Чтение и сохранение пользовательских настроек. |
| `Properties` | Метаданные сборки. |

В корне проекта остаются `App.xaml`, `App.xaml.cs` (запуск приложения и создание компонентов) и `FlyTracker.csproj`. Пространства имён соответствуют папкам. `bin/` и `obj/` содержат результаты сборки.

## Сборка

Из корня репозитория:

```powershell
dotnet build FlyTracker -c Release
```
